TurismoUY - Sistema de Gestión Turística

Descripción General

TurismoUY es un sistema integral de gestión turística desarrollado en Java con arquitectura en capas. El sistema permite la gestión de usuarios (turistas y proveedores), actividades turísticas, salidas e inscripciones, proporcionando tanto una interfaz web como una aplicación de escritorio.

Arquitectura del Sistema

Capas de la Aplicación

  • Presentación (presentation): Interfaces gráficas Swing para aplicación de escritorio
  • Controladores (core.controller): Lógica de negocio y coordinación
  • Handlers (core.handler): Capa de persistencia y acceso a datos JPA
  • Entidades (core.entity): Modelo de dominio mapeado con JPA
  • DTOs (core.dto): Objetos de transferencia de datos entre capas

Patrones de Diseño Utilizados

  • Singleton: Factory y Handlers
  • Factory: Creación de controladores ({@link turismouyapp.core.factory.FactoryUyTourism})
  • DAO (Data Access Object): Handlers de persistencia
  • DTO (Data Transfer Object): Transferencia de datos entre capas
  • Facade: Interfaces de controladores

Tecnologías Principales

  • Java SE 17: Plataforma base
  • Jakarta Persistence API (JPA) 3.1: ORM y persistencia
  • EclipseLink 4.0.4: Implementación JPA
  • HSQLDB 2.7.2: Base de datos embebida
  • Java Swing: GUI de escritorio
  • Apache Tomcat 11: Servidor de aplicaciones (para web)

Modelo de Dominio

Entidades Principales

  • {@link turismouyapp.core.entity.User}: Clase abstracta base para usuarios
    • {@link turismouyapp.core.entity.Tourist}: Usuario turista
    • {@link turismouyapp.core.entity.Supplier}: Usuario proveedor de actividades
  • {@link turismouyapp.core.entity.TouristActivity}: Actividad turística ofrecida por un proveedor
  • {@link turismouyapp.core.entity.TouristOuting}: Salida específica de una actividad
  • {@link turismouyapp.core.entity.Inscription}: Inscripción de un turista a una salida

Relaciones del Modelo

Supplier (1) -------> (N) TouristActivity
TouristActivity (1) -> (N) TouristOuting
Tourist (N) <-------> (N) TouristOuting (a través de Inscription)

Controladores Principales

{@link turismouyapp.core.controller.UserController}

Gestiona todas las operaciones relacionadas con usuarios:

  • Alta de turistas y proveedores
  • Consulta de perfiles de usuario
  • Modificación de datos de usuario
  • Listado de usuarios por tipo

{@link turismouyapp.core.controller.TouristActivityController}

Gestiona actividades turísticas:

  • Alta y modificación de actividades
  • Consulta de actividades por diversos criterios
  • Ranking de actividades
  • Aprobación de actividades

{@link turismouyapp.core.controller.TouristOutingAndInscriptionController}

Gestiona salidas e inscripciones:

  • Registro de salidas turísticas
  • Inscripción de turistas a salidas
  • Consulta de salidas e inscripciones
  • Gestión de cupos y disponibilidad

Flujo de Trabajo Típico

Crear un Nuevo Usuario Turista

1. Capa Presentación: CreateUser.java (GUI Swing)
2. Factory: FactoryUyTourism.getInstance().getIUserController()
3. Controlador: UserController.dataEntry(dtTourist) - Validación
4. Controlador: UserController.confirmRegistration() - Confirmación
5. Handler: UserHandler.addUser(tourist) - Persistencia
6. EntityManager: persist(tourist) - JPA
7. HSQLDB: INSERT INTO Users, Tourists

Inscribirse a una Salida Turística

1. Capa Presentación: InscriptionToTouristOuting.java
2. Controlador: TouristOutingAndInscriptionController.dataEntryInscription()
3. Validaciones: Verificar cupos, fechas, inscripciones previas
4. Handler: TouristOutingAndInscrptionHandler.addInscription()
5. EntityManager: persist(inscription)
6. HSQLDB: INSERT INTO Inscriptions

Manejo de Excepciones

El sistema define excepciones de negocio específicas (ver {@link turismouyapp.core.exceptions}) que son lanzadas cuando se violan reglas de negocio:

  • {@link turismouyapp.core.exceptions.RepeatedUserNicknameException}: Nickname ya existe
  • {@link turismouyapp.core.exceptions.RepeatedUserEmailException}: Email ya registrado
  • {@link turismouyapp.core.exceptions.RepeatedInscriptionToTouristOutingException}: Usuario ya inscrito
  • {@link turismouyapp.core.exceptions.ActivityDoesNotExistException}: Actividad no encontrada

Configuración de Persistencia

La configuración JPA se encuentra en src/main/resources/META-INF/persistence.xml:

  • Persistence Unit: turismoUyDB-Server
  • Provider: EclipseLink
  • URL JDBC: jdbc:hsqldb:hsql://localhost:9001/turismoUyDB
  • DDL Generation: create-or-extend-tables (automático)

Inicio Rápido

Obtener Instancia de Controlador

{@code
FactoryUyTourism factory = FactoryUyTourism.getInstance();
IUserController userCtrl = factory.getIUserController();
ITouristActivityController actCtrl = factory.getITouristActivityController();
}

Crear Usuario Turista

{@code
DtTourist tourist = new DtTourist(
    "juanperez",           // nickname
    "Juan",                // nombre
    "Pérez",               // apellido
    "juan@example.com",    // email
    LocalDate.of(1990, 5, 15), // fecha nacimiento
    "Uruguay"              // nacionalidad
);

try {
    userCtrl.dataEntry(tourist);
    userCtrl.confirmRegistration();
    System.out.println("Usuario creado exitosamente");
} catch (RepeatedUserNicknameException | RepeatedUserEmailException e) {
    System.err.println("Error: " + e.getMessage());
}
}
